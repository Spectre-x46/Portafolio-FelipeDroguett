# Portfolio Web - Felipe Droguett 💻

¡Hola! Bienvenido al repositorio de mi portfolio personal. 

Este proyecto es la demostración práctica de mi transición profesional: **de 10 años en Operaciones y Ventas hacia el Desarrollo Full Stack**. Aquí no solo hay código, hay una historia de reinvención y aprendizaje constante.

## 🎯 ¿Qué es esto?

Es una página web diseñada para presentar quién soy, qué he hecho y qué estoy aprendiendo. No quería usar una plantilla genérica, así que me esforcé en construir algo que se sienta "mío", con un diseño moderno y oscuro (Dark Mode) que refleja mis intereses en tecnología, Linux y seguridad.

## 🛠️ Tecnologías que usé (Stack)

Como estoy empezando, me enfoqué en dominar las bases:

*   **HTML5:** Usé etiquetas semánticas (header, nav, section, footer) para que el código sea ordenado y fácil de leer.
*   **CSS3:** Usé variables CSS (`:root`) para manejar los colores neón y creé mis propias clases para efectos de brillo y vidrio (Glassmorphism).
*   **Bootstrap 5:** Me ayudó con la estructura general (Grid System) y la barra de navegación responsiva.
*   **JavaScript:** Lo justo y necesario para inicializar librerías y efectos visuales.
*   **AOS (Animate On Scroll):** Una librería externa que hace que los elementos aparezcan suavemente mientras bajas por la página.

## ✨ Características de Diseño

Quería lograr una estética "Cyber-Seguridad" pero profesional:
*   **Paleta de Colores:** Slate 900 (fondo oscuro) + Cyan Neón (acentos).
*   **Glassmorphism:** La barra de navegación tiene un efecto de vidrio esmerilado blur.
*   **Diseño Responsivo:** Se ve bien en el celular y en el PC (¡pruébalo!).
